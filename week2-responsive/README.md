# Week 2 Day 2 — Responsive Design

## Project

A mobile-first landing page built with semantic HTML5 and CSS3.

## Sections

- Hero
- Features
- Testimonials
- Contact call-to-action
- Footer

## Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media queries
- Chrome DevTools

## Responsive breakpoints

| Breakpoint | Layout |
|---|---|
| 320px | Mobile |
| 768px | Tablet |
| 1024px | Laptop |
| 1440px | Large desktop |

The features section uses CSS Grid, and the navigation uses Flexbox.
