# PennyWise — Expense Tracker

A responsive personal finance application built with HTML, CSS, and JavaScript.

## Features

- Add income and expense transactions.
- Calculate total income, total expenses, and balance.
- Delete individual transactions or clear all transactions.
- Save transaction data in browser localStorage.
- Responsive layout for desktop, tablet, and mobile.
- Indian Rupee currency formatting.

## Technologies Used

- HTML5
- CSS3, Flexbox, CSS Grid, and media queries
- JavaScript ES6+
- DOM manipulation and event delegation
- Browser localStorage
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open `expense-tracker/index.html` using VS Code and Live Server.
3. Add transactions using the form.

## Data Storage

Transactions are stored locally in the browser. They are not synchronized between devices.

## Project Structure

- `index.html` — Application structure
- `styles.css` — Responsive styling
- `script.js` — Transaction logic and localStorage
